7/*!
8Dependencies are broken down by feature category, then feature.
9
10# Core Dependencies (on all features)
11* [`either`] - [`either::Either`] type for two case results.
12* [`serde`] - Most popular approach for (de)serialization.
13* [`derive_getters`] - Avoiding manual implemenations for getters.
14* [`error_stack`] - More descriptive error handling.
15* [`nix`] - Unix calls, when on Unix platforms.
16* [`thiserror`] - Reduce dev burden for writing errors.
17* [`embed_doc_image`] - Put images in documentation.
18
19# Library Functionality
20* `async`
21    * [`futures`] - The most popular library for core [`future`][`std::future`] functionality.
22    * [`cfg_if`] - Prevents copy-pasting for complex feature definitions.
23* `unsafe_array`
24    * [`stable_deref_trait`] - [`StableDeref`][`stable_deref_trait::StableDeref`] Guarantees that a container variable can be moved without
25        invalidating element references.
26* `directory`
27    * [`uuid`] - [`Uuid::new_v4`][`uuid::Uuid::new_v4`] is used for random file names.
28
29# Async Executors
30
31* `tokio`
32    * [`tokio`]
33    * [`tokio_util`] - Convert from tokio I/O traits to [`futures`] I/O traits.
34    * [`async_scoped`] - Provides a scoped async block not available in base [`futures`], so blocking
35    * thread handles can have less than `'static` lifetimes.
36* `smol`
37    * [`smol`]
38
39# Disk Types
40* `all_disks`
41    * All dependencies below.
42* `encrypted`
43    * [`secrets`] - Provides protected memory via [`libsodium`](https://doc.libsodium.org/) to make
44        memory snooping difficult.
45    * [`aes_gcm`] - Provides an encryption algorithm to protect data written to disks.
46    * [`stable_deref_trait`] - [`StableDeref`][`stable_deref_trait::StableDeref`] Guarantees that the secret container can be moved without
47        invalidating element references.
48* `mmap`
49    * [`memmap2`] - Cross-OS memory mapping wrapper.
50    * [`stable_deref_trait`] - [`StableDeref`][`stable_deref_trait::StableDeref`] Guarantees that the mmap array is valid, even when the handle is moved.
51* `network`
52    * Dependencies from `async`
53    * [`reqwest`] - Backend for remote communications.
54    * [`bytes`], [`http_serde`], [`url`] - (De)serialization definitions for [`reqwest`].
55* `zstd`
56    * [`zstd`]
57    * [`num_traits`] - Generic for unsigned numbers.
58* `async_zstd`
59    * `async` dependencies.
60    * [`num_traits`] - Generic for unsigned numbers.
61    * [`async_compression`] - Async zstd implementation.
62* `zstdmt`/`async_zstdmt`
63    * `zstd`/`async_zstd` dependencies.
64
65# Predefined Formats
66* `all_formats`
67    * All dependencies below
68
69#### Synchronous Formats

71    * [`bincode`]
72* `serde_json`
73    * [`serde_json`]
74* `simd_json`
75    * [`simd_json`]
76* `csv`
77    * [`csv`]
78
79#### Async Formats
80* `async_bincode`
81    * [`async_bincode`]
82* `async_csv`
83    * [`csv_async`]
